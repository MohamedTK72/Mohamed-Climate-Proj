# صوت المتفوقين من أجل المناخ

موقع تعليمي بسيط من إعداد **محمد توفيق سعيد**، الطالب بمدرسة المتفوقين الثانوية بنين بعين شمس (MAS).

يتحدث الموقع عن:

- التغير المناخي وتأثيره على حياتنا.
- دور التكنولوجيا في تقليل التلوث والتكيف مع التغيرات.
- خطوات بسيطة يستطيع الطالب أو أي شخص تنفيذها.
- مصادر وروابط للتعلم والتبرع لجمعيات ومبادرات تهتم بالبيئة.

## الملفات الأساسية

الموقع مكتوب بطريقة بسيطة، والملفات المهمة هي:

```text
index.html  # صفحة الموقع الأساسية
style.css   # ألوان وتنسيق الموقع
main.js     # التفاعلات وتشغيل الموقع
```

## تشغيل الموقع

بعد تثبيت Node.js و pnpm، يمكن تشغيل الموقع بالأمر:

```bash
pnpm run dev
```

ثم فتح الرابط الذي يظهر في شاشة التشغيل.

## ملاحظات

- الموقع باللغة العربية واتجاهه من اليمين إلى اليسار.
- يمكن فتح قائمة الهاتف من زر القائمة العلوي.
- يوجد زر لتغيير ألوان الموقع إلى الوضع الليلي.
- يمكن الضغط على خطوات العمل لتحديد ما تم إنجازه.
- روابط التبرع والمصادر تفتح في صفحة جديدة.
